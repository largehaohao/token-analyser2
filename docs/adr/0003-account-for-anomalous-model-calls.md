# 异常金额按可确认的模型调用归因，不按工具数平摊

日志通常只能把用量可靠地关联到模型调用或更粗的汇总，无法证明一次 Read 或 wait 的独立计费成本。为避免制造精确但没有依据的“浪费金额”，用户在第四轮确认：仅将符合完整异常规则、可观察行为均异常且用量可计价的调用计入疑似可优化费用；混合调用只展示关联调用费用，不按工具次数平摊。代价是金额覆盖更保守，部分可疑行为只能给出证据而没有可优化金额。

同一调用同时命中多个规则时只计一次，首次正常基线操作不计入。未知费用不填零，必要操作标记不修改原始用量；所有结果仍是异常相关的估算，不是已确认账单损失或保证可节省金额。
