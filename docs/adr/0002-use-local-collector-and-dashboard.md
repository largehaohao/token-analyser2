# 用本地只读采集服务支持实时 dashboard

MVP 需要持续读取本机日志，并以日志写出新用量后 5 秒内更新为目标；普通文件导入本身不能持续跟随日志增长，而浏览器文件句柄存在支持和授权边界。用户在第三轮选择主动启动本地只读采集服务、通过浏览器查看 dashboard，同时保留历史文件导入；代价是首次使用需要启动一个本地进程，而非仅打开一个网页。

服务仅向本机开放，只读取用户明确选择的日志目录；不自启动、不扫描其他目录、不修改 Agent 配置、不自动暂停或终止 Agent。该决定遵守 [ADR 0001](0001-keep-session-content-on-device.md) 的原始内容不出设备及不另存历史副本边界。

第四轮确认首发优先验证 macOS 与主流 Chromium 浏览器。关闭网页不自动停止服务；停止采集后仍可查看本次结果，退出服务才清空临时内容。这些操作都不终止 Coding Agent。
