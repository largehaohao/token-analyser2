# MVP 的原始会话内容不离开用户设备

会话日志可能包含源代码、提示词、路径和工具输出。用户在第一轮访谈中选择全部本地处理，因此 MVP 的读取与分析在用户设备内完成，不向服务端上传这些原始内容。该边界优先保障隐私，代价是不使用云端日志解析、集中诊断或原始日志同步；后续报告分享须单独确定脱敏规则，不能以“统计分析”为由绕过这个边界。

用户随后增加实时会话分析展示，该数据边界同样适用于运行中会话的持续采集；第三轮确定采用[本地只读采集服务与浏览器 dashboard](0002-use-local-collector-and-dashboard.md)。

第二轮进一步确认：MVP 不另存会话内容和历史分析结果，只保留费率、规则等偏好；再次查看时重读来源日志。这放弃了无需重读即可恢复分析的便利，以避免分析器额外保留敏感资料。
